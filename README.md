## FEATURES
1. **Automatic hardware detection**: Detects your PC components and prints them on top of the application.
2. **Real-time alerts**: 
3. **Data Logging**
4. **Modern and slick interface**
5. **lightweight**: the program is extremely lightweight and can run perfectly even on bad hardware.
## INSTALLATION
The simpleest way to install it is via released installer.
1. Go to the [Releases](../../releases) page.
2. Download the latest **`ChillinPC_installer.exe`**.


*(Note: Since the application does not have a commercial Windows code-signing certificate, Windows Defender may show a warning upon launch. This is normal for independent Python applications – simply click "More info" and "Run anyway". The source code is completely open and verifiable right here in the repository!)*
